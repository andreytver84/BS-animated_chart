# BS Animated Chart

![Joomla 5 Compatible](https://img.shields.io/badge/Joomla-5.x-blue.svg)

**RU:** Модуль вывода анимированного графика статистики для Joomla 5 от [Bestsite Studio](https://bestsite-tver.ru).  
Позволяет наглядно отображать рост показателей (количество объектов и квадратные метры) по годам.

**EN:** Animated statistics chart module for Joomla 5 by [Bestsite Studio](https://bestsite-tver.ru).  
Allows you to visually display the growth of indicators (number of objects and square meters) by year.

---

## 🇷🇺 Русская версия

### Возможности
- Плавная анимация роста столбцов при скролле (появлении на экране).
- Анимация счетчика цифр (от 0 до целевого значения).
- Адаптивная типографика и ширина столбцов (размеры плавно меняются в зависимости от ширины экрана с помощью функции `clamp()`).
- Раздельная настройка цветов для столбцов "Объекты" и "Метры" прямо из админки.
- Удобное добавление годов и значений через Subform.

### Установка и использование
1. Установите ZIP-архив модуля через стандартный менеджер расширений Joomla (`Система -> Установка расширений`).
2. Перейдите в менеджер модулей и опубликуйте `BS Animated Chart` в нужной позиции.
3. В настройках модуля задайте цвета, впишите заголовок и добавьте нужные данные в разделе "Данные графика".

## 🇬🇧 English Version

### Features
- Smooth column height animation triggered on scroll (Intersection Observer).
- Number counter animation (from 0 to target value).
- Fluid typography and column widths (sizes scale smoothly based on screen width using CSS `clamp()`).
- Separate color pickers in the admin panel for "Objects" and "Meters" columns.
- Easy addition of years and values via repeatable Subform fields.

### Installation and Usage
1. Install the module ZIP archive via the standard Joomla extension manager (`System -> Install Extensions`).
2. Go to the Module Manager and publish `BS Animated Chart` in the desired position.
3. In the module settings, choose your colors, enter the title, and add the required data in the "Chart Data" section.
